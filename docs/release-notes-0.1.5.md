# Cue 0.1.5

Faster seeking, resume from Finder, and Mac playback extras.

## Install

1. Download **Cue-0.1.5.dmg** below.
2. Open the disk image and drag **Cue** into **Applications**.
3. Open Cue from Applications.

Requires **macOS 26** or later.

If macOS says the app cannot be opened, Control-click Cue → **Open**.

## Highlights

- Arrow-key skip jumps as soon as IINA: video renders off the main thread
- Reopening the same file from Finder or Open With resumes where you stopped
- Audio track, volume, speed, and picture settings are remembered per file
- Now Playing and headphone buttons
- Display stays awake while a video is playing
- Timeline hover previews, chapter marks, A–B loop, and Picture in Picture
