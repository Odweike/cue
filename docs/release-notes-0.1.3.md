# Cue 0.1.3

Smoother playback bar and aligned sliders.

## Install

1. Download **Cue-0.1.3.dmg** below.
2. Open the disk image and drag **Cue** into **Applications**.
3. Open Cue from Applications.

Requires **macOS 26** or later.

If macOS says the app cannot be opened, Control-click Cue → **Open**.

## Highlights

- Floating playback bar follows the mouse at display refresh
- Timeline no longer steps at 10 Hz
- Speed and audio delay sliders use a centered tick ruler
