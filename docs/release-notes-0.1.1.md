# Cue 0.1.1

Playback, subtitles, and settings polish.

## Install

1. Download **Cue-0.1.1.dmg** below.
2. Open the disk image and drag **Cue** into **Applications**.
3. Open Cue from Applications.

Requires **macOS 26** or later.

If macOS says the app cannot be opened, Control-click Cue → **Open**.

## Highlights

- Space toggles play/pause without the system beep
- Side settings panel no longer stalls the video when opened or when switching tabs
- Timeline scrubbing stays in sync on long videos; hour timecodes are not clipped
- Embedded and sidecar subtitles are loaded automatically
- Slider tick marks sit on a ruler under Speed and Audio Delay only
