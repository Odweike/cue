# Cue 0.1.0

First public release of **Cue**, a native macOS video player with local subtitle generation.

## Install

1. Download **Cue-0.1.0.dmg** below.
2. Open the disk image and drag **Cue** into **Applications**.
3. Open Cue from Applications.

Requires **macOS 26** or later.

If macOS says the app cannot be opened, Control-click Cue → **Open**.

## Highlights

- Play MKV, MP4, MOV, and other formats through libmpv
- Floating, draggable playback controls
- Import two subtitle tracks (SRT, VTT, ASS) with independent styles
- Generate subtitles on-device with Apple Speech, including recognize-while-watching
- Export tracks as SRT
