# Cue 0.1.6

Embedded subtitles, delay, and up to three tracks.

## Install

1. Download **Cue-0.1.6.dmg** below.
2. Open the disk image and drag **Cue** into **Applications**.
3. Open Cue from Applications.

Requires **macOS 26** or later.

If macOS says the app cannot be opened, Control-click Cue → **Open**.

## Highlights

- Embedded MKV subtitle tracks show up like IINA, including PGS and other bitmap formats
- Pick up to three tracks; the list matches the audio picker
- Subtitles sit at the bottom by default and can be moved to the top
- Subtitle delay, same ±5 s range as audio delay
