Built for local video, not a streaming clone

Cue is a Mac player for files you already have — including MKV — with subtitles you can generate without uploading the movie.

MKV, MP4, MOV

Playback goes through an embedded LGPL build of libmpv, so common local containers and codecs open without converting first.

On-device subtitles

Apple SpeechAnalyzer and SpeechTranscriber run on your Mac. Generate a timed track while watching, or transcribe the whole file.

Imported tracks

Load up to two SRT, VTT, or ASS files. Embedded MKV tracks and sidecar files next to the video are picked up automatically.

Independent styles

Each visible track has its own overlay style. Named profiles keep a look you reuse across files.

Playback tools

Audio track picker, A/V sync, speed, hardware decode, crop, rotation, aspect, and a floating control bar that remembers layout.

Stays out of the cloud

No account. No analytics. Files, settings, and generated subtitles stay on the Mac. Open source notices live in Help.

Install

  1. Download the disk image. Use the button above for Cue-0.1.2.dmg. SHA-256 checksum: Cue-0.1.2.dmg.sha256.
  2. Open the DMG and drag Cue into Applications.
  3. Launch from Applications. If macOS says the app cannot be opened, Control-click Cue → Open.

Requires macOS 26 or later for Apple’s on-device speech APIs.

FAQ

Is Cue free?

Yes. Cue is MIT-licensed. libmpv and related libraries keep their LGPL terms inside the app.

Does it replace IINA?

It is a separate player focused on local files plus on-device subtitle generation. If you only need MKV playback, other players exist; Cue exists so subtitles can be written on the Mac without a cloud service.

Where is the source?

Public repository: github.com/Odweike/cue. Latest GitHub release: v0.1.2.

Is the app notarized?

Not yet. It is signed for development/local distribution. First launch may need Control-click → Open.
